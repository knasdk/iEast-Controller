SPOTIFY OPSÆTNING

Sådan får du et Client ID

  1. Åbn Spotify Dashboard

    Gå til developer.spotify.com/dashboard, og log ind med den Spotify-konto, du vil bruge.

  2. Opret en app

    Klik på Create app. Giv appen et valgfrit navn, for eksempel iEast Controller, og skriv en kort beskrivelse.

  3. Tilføj Redirect URI

    Indsæt adressen herunder præcist som vist. Den følger den adresse, du bruger til at åbne controlleren.

    Indlæser...

  4. Vælg Web API

    Markér Web API under de API'er eller SDK'er, appen skal bruge, acceptér Spotifys vilkår, og opret appen.

  5. Kopiér Client ID

    Åbn appens Settings eller Basic Information, kopiér værdien ved Client ID, og indsæt den i feltet bag denne vejledning. Du skal ikke bruge Client Secret.

  6. Gem og forbind

    Klik på Gem indstillinger. Gå derefter til Spotify i controlleren, og klik på Forbind Spotify.
